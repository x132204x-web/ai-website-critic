# Real-world trial results

These user-journey reports were generated on July 12, 2026 using AI Website Critic. Every trial starts with a specific person, situation, task, and observable success criteria, then follows real browser actions to a meaningful handoff. Website content and metrics change over time; Lighthouse scores are diagnostic, not durable benchmarks.

- [Linear](linear.md)

The reusable journey specifications live in [`examples/trials`](../examples/trials). Raw screenshots and JSON stay under the gitignored `audits/` directory because they are bulky, time-sensitive third-party artifacts. Each report identifies its evidence and limitations.
